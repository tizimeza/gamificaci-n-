# El Rosco Eléctrico

Juego educativo de Pasapalabra sobre electricidad. La docente lee una definición y el alumnado dice la palabra correspondiente antes de que termine el cronómetro.

## Jugar localmente

Abre `index.html` en un navegador moderno. El juego incluye diez definiciones, cronómetro de 30 segundos, marcador para dos equipos y la opción de crear definiciones adicionales.

La aplicación es estática y no requiere instalación, dependencias locales ni proceso de build. Tailwind CSS, Font Awesome y las fuentes tipográficas se cargan desde CDN, por lo que se necesita conexión a internet para esos recursos.

## Publicar en Netlify

En Netlify, importa este repositorio desde GitHub. La configuración de `netlify.toml` publica la carpeta raíz (`.`); no hace falta configurar un comando de build.

También puedes arrastrar la carpeta del proyecto a Netlify Drop para una publicación manual.
